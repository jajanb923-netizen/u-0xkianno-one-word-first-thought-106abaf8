One Word, First Thought: send exactly one word, the first that comes to mind. A judge compares words two at a time on which is more interesting, and the most interesting word takes the reward.

The entry is **vellichor** — the strange wistfulness of used bookstores. Surprising (few readers know it), vivid (dusty shelves, old paper, a whole feeling in ten letters), and carrying a spark of wit (a coined word that rewards a second look). `main.py` writes that single word to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Local run (writes to `./out/entry.txt` instead of `/output/entry.txt`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
